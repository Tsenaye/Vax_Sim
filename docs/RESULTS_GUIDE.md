# Results Guide

The 20 logged model channels are, in order: wind speed, rotor speed, mechanical torque, mechanical power, machine q-current, DC voltage, grid d-current, grid q-current, active power, reactive power, PCC d-voltage, PCC q-voltage, PCC magnitude, PLL angle, phase-a current, phase-a voltage, current magnitude, SCR, Cp, and tip-speed ratio.

MAT files preserve full structures and parameter copies. CSV tables summarize cases, SCR sweep, controller sweep, mitigation and modal comparison. Figures are numbered in report order. Always quote values from these generated artifacts and retain enough decimal places to respect the FFT resolution reported in the metrics.
