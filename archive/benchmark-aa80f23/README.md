# Historical reduced-order benchmark

These documents, scripts, reports, result tables and snapshots belong to the validated reduced-order model at commit `aa80f23`, also preserved as Git tag `benchmark-aa80f23`. They are retained for comparison and reproducibility only. They do not describe or validate the authoritative physical `model/Vataleni_PMSG_SSO_Final.slx` on the current branch. In particular, the benchmark's 4.84 Hz mode, controller gains and 20-check validation must not be cited as final physical-model results.

To rerun the exact historical model, check out the Git tag in a separate worktree.
